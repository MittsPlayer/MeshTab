# MeshTab
Editor de modelação 3D no navegador, inspirado no Blender, feito com Three.js. Funciona em PC e telemóvel, sem instalação.  - Primitivas, mover/rodar/escalar, snap, duplicar e subdividir - Modo de edição de vértices - Desfazer/refazer e atalhos do Blender (G, R, S, Tab, Shift+A...) - Exporta para .glb, .gltf, .obj, .stl e .fbx
